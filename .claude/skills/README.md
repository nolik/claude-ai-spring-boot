# Skills

These are the workspace-level skills for the gv Java services. Claude Code picks a skill by its `SKILL.md` frontmatter `description`. This README is for humans and is not loaded.

| Skill | Purpose |
|---|---|
| [code-quality](code-quality/) | Java review checklist, workspace-specific checks, report format |
| [design-patterns](design-patterns/) | GoF patterns with Java/Spring examples |
| [jpa-patterns](jpa-patterns/) | JPA/Hibernate fetching and transaction pitfalls |
| [logging-patterns](logging-patterns/) | SLF4J and Spring Boot structured logging |
| [spring-boot](spring-boot/) | Spring Boot conventions for the gv services |

To add a skill, create `.claude/skills/<name>/SKILL.md` with `name` and `description` frontmatter, then add a row here. See https://code.claude.com/docs/en/skills.
